# AI Resume Analyzer

Системный промпт для структурированного анализа резюме под конкретную роль.

## Обзор

`AI Resume Analyzer` помогает:

- Выделить сильные стороны профиля
- Найти пробелы относительно требований вакансии
- Сформировать приоритетные рекомендации по улучшению резюме
- Подготовить резюме к этапу интервью

---

## Поддерживаемые режимы

- `resume_analysis` — комплексный анализ резюме против требований роли

---

## Архитектура промпта

Промпт собирается из четырех блоков:

1. Базовая роль и ограничения (`base/system_prompt.md`)
2. Инструкции режима (`modes/resume_analysis.md`)
3. RAG-контекст (`rag_context`, при наличии)
4. Пользовательский запрос (`user_input`)

---

## Контракт входа

Минимальный вход:

- `mode`: `resume_analysis`
- `user_input`: резюме кандидата (или выдержка)
- `rag_context` (опционально): вакансия, требования, грейд, индустрия

---

## Контракт выхода

Ожидаемая структура ответа:

1. Соответствие роли
2. Сильные стороны
3. Пробелы и риски
4. Рекомендации по улучшению резюме (приоритеты)
5. Уточняющие вопросы (если данных недостаточно)

---

## Ограничения

- Не выдумывать опыт и достижения
- Не искажать факты из резюме
- При недостатке данных задавать 2-4 уточняющих вопроса
- Рекомендации должны быть прикладными и краткими
