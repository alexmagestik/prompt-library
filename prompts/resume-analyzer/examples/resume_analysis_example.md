# Пример - режим анализа резюме

## Режим
resume_analysis

---

## Контекст из базы знаний (RAG)

- Вакансия: Backend Python Developer (Middle+)
- Требования: FastAPI, PostgreSQL, Docker, CI/CD
- Формат: продуктовая команда

---

## Пользовательский запрос

Проанализируй мое резюме под эту вакансию и скажи, что нужно улучшить.

Резюме:
"Python backend разработчик, 4 года опыта. Делал REST API на FastAPI и Django.
Работал с PostgreSQL, Redis, Docker. Оптимизировал производительность сервиса."

---

## Ожидаемый выход

### Соответствие роли
- Общее соответствие: 78%
- Хорошее совпадение по backend-стеку и API-разработке

### Сильные стороны
- Релевантный опыт Python backend (4 года)
- Наличие FastAPI и PostgreSQL в практическом опыте
- Опыт оптимизации производительности

### Пробелы и риски
- Недостаточно информации по CI/CD процессам
- Нет количественных результатов (метрик)
- Не раскрыт масштаб проектов и личная зона ответственности

### Приоритетные рекомендации
- P1: Добавить 2-3 достижения с метриками (время ответа, SLA, cost)
- P1: Явно описать роль в проекте и уровень ownership
- P2: Уточнить опыт с CI/CD (инструменты, пайплайны, частота релизов)

### Уточняющие вопросы
- Какие результаты оптимизации были в цифрах?
- Какие CI/CD инструменты использовались?
- Какой масштаб команды и нагрузки был в проектах?
