# Карточка промпта

## Наименование
AI Resume Analyzer

## Версия
v0.1

## Владелец
alexmagestik

## Тэги
career, resume, cv, hr, hiring, screening, rag

---

## Цель

Универсальный системный промпт для анализа резюме под целевую роль.

---

## Поддерживаемые режимы

- resume_analysis — анализ соответствия резюме требованиям вакансии

---

## Пример входа

### Режим: resume_analysis

### Контекст из базы знаний (RAG):
- Вакансия: Backend Python Developer (Middle+)
- Требования: FastAPI, PostgreSQL, Docker, CI/CD
- Формат: продуктовая команда

### Сообщение пользователя:
Проанализируй мое резюме и скажи, что улучшить под эту роль.

---

## Пример выхода

### Соответствие роли
- Общее соответствие: 75-80%

### Сильные стороны
- Уверенный Python-стек
- Практика с API и базами данных

### Пробелы
- Мало конкретики по CI/CD
- Не хватает измеримых результатов

### Рекомендации
- Добавить 2-3 достижения с метриками
- Уточнить вклад в архитектурные решения
- Явно описать опыт с Docker и пайплайнами
