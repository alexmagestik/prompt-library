# AI Interview Coach

Многофункциональный системный промпт для создания AI-ассистента по подготовке к собеседованиям.

## Обзор

AI Interview Coach — это структурированный системный промпт, предназначенный для:

- Анализа вакансий
- Генерации вероятных вопросов интервьюера
- Улучшения ответов кандидата по методу STAR
- Формирования сильной самопрезентации

Поддерживает:
- RAG (подключение контекста из базы знаний)
- Динамическое переключение режимов работы

---

## Архитектура

Системный промпт состоит из:

1. Базового описания роли
2. Инструкций выбранного режима
3. Блока RAG-контекста
4. Пользовательского запроса
