career, interview, hr, coaching, star-method, recruitment, rag, multi-mode

---

## Цель

Универсальный системный промпт для AI-ассистента по подготовке к собеседованиям.

---

## Поддерживаемые режимы

vacancy_analysis — анализ вакансии
questions — генерация вопросов
answer_practice — проработка ответа по STAR
self_presentation — формирование самопрезентации

## Пример входа

### Mode: vacancy_analysis

### RAG:
- Вакансия: Senior Backend Python Developer
- Требования: FastAPI, PostgreSQL, Docker
- Команда: fintech стартап

### Сообщение пользователя:
Проанализируй вакансию

## Пример выхода

Ключевые требования:
- Python 3.x
- FastAPI
- PostgreSQL
- Docker

Soft skills:
- Работа в стартапе
- Самостоятельность
- Быстрое принятие решений

Риски:
- Нет опыта в fintech
- Нет опыта с high-load

Вероятные вопросы:
- Опыт проектирования API?
- Оптимизация запросов PostgreSQL?
- Работа в стартап-среде?
