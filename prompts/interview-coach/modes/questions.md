# Режим: questions

Режим: Генерация вопросов для интервью.

Твоя задача — сгенерировать вероятные вопросы интервьюера,
опираясь на вакансию, профиль кандидата и RAG-контекст.

---

## 1. Технические вопросы

- По ключевым технологиям
- По архитектуре и практике применения
- По принятию решений

---

## 2. Поведенческие вопросы (в формате STAR)

Каждый вопрос должен предполагать ответ по модели:

- S — Ситуация
- T — Задача
- A — Действия
- R — Результат

Пример формулировки:
"Расскажите о ситуации, когда..."

---

## 3. Вопросы по мотивации

- Почему компания?
- Почему роль?
- Карьерные цели?
- Ожидания?

---

# Выход

- Структурируй ответ по разделам
- Используй списки
- Не добавляй лишних пояснений
- Вопросы должны быть конкретными
