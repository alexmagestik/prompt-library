## Ожидаемый вывод

### Улучшенная версия (STAR)

**S — Ситуация**  
В e-commerce проекте время ответа API превышало 800 мс из-за медленных SQL-запросов.

**T — Задача**  
Необходимо было снизить время ответа сервиса и уменьшить нагрузку на базу данных.

**A — Действия**  
- Проанализировал медленные запросы через EXPLAIN
- Добавил индексы для часто используемых полей
- Оптимизировал JOIN-запросы
- Вынес тяжёлые вычисления в кэш

**R — Результат**  
Снизил среднее время ответа API с 800 мс до 250 мс (-69%), что позволило повысить конверсию на 6%.
